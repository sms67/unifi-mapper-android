# نقشه‌بردار شبکه UniFi — نسخه اندروید بومی (UniFi Network Mapper)

اپلیکیشن بومی اندروید برای **برداشت و جانمایی اکسس‌پوینت‌های UniFi** — پورت کامل اپ وب مرجع با Kotlin،
رابط فارسی راست‌به‌چپ با همان پالت کرم/کاراملی، بدون نیاز به سرویس‌های گوگل.

## امکانات (مطابق اپ مرجع + قابلیت‌های اندروید)

- **پروژه‌ها**: ساخت پروژه (نام، سازمان، سایت، ساختمان، توضیح، تاریخ)، فهرست پروژه‌های اخیر، ادامه برداشت، پروژه نمونه DEMO، پاک‌سازی دو مرحله‌ای
- **برداشت**: مدیریت ناحیه/طبقه، کالیبراسیون مقیاس با فاصله مرجع + قفل مقیاس، سه نمای همزمان قابل جابه‌جایی:
  - نمای دوربین (CameraX) با شبکه راهنما
  - نمای بالا 2D روی شبکه متریک (ثبت نقطه با لمس هنگام برداشت دستی)
  - پرسپکتیو ۶۰ درجه (چرخش با کشیدن، زوم)
- ابزارها: شروع/توقف برداشت دستی، ثبت نقطه، ثبت دیوار (از دو نقطه آخر)، ثبت مانع، ثبت اتاق، لغو آخرین نقطه، پایان ناحیه
- **نقشه و جانمایی**: انتخاب AP، لمس برای جانمایی، کشیدن برای جابه‌جایی (پس‌گیری AP نزدیک)، لایه تخمینی پوشش، فاصله تا نزدیک‌ترین نقطه مرجع
- **اکسس‌پوینت‌ها**: فرم ثبت دستی (نام، SSID، BSSID، مدل UniFi، باند ۲٫۴/۵/۶ گیگاهرتز، RSSI، ارتفاع نصب، وضعیت موجود/پیشنهادی، یادداشت)
  + **اسکن زنده وای‌فای دستگاه** (WifiManager واقعی): نتایج با RSSI و BSSID واقعی به‌عنوان پیشنهاد در فرم ثبت می‌شوند و ثبت نهایی با تأیید شماست؛ فیلتر بر اساس جست‌وجو/باند/سیگنال/ناحیه
- **کنترل کیفیت**: هفت هشدار QC مرجع (مقیاس، نقاط کم، ناحیه خالی، AP بدون موقعیت، DEMO، سیگنال ضعیف، اطمینان مقیاس)
- **خروجی‌ها**:
  - تصویر نمای بالا · PNG (با بلوک عنوان و آمار پروژه)
  - مدل 3D · **OBJ بر حسب متر، Z-up** (مسیر، نقاط، جعبه‌های دیوار، موانع، هشت‌وجهی APها با نام گروه) — بازشدن در **3ds Max** از مسیر File → Import → Geometry → OBJ
  - گزارش ساختاریافته · JSON (پروژه + نواحی + نقاط + APها + QC)
- ذخیره‌سازی محلی خودکار (JSON) — هیچ داده‌ای جایی ارسال نمی‌شود

## نصب APK

1. آخرین APK امضاشده را از [بخش Releases](../../releases) دانلود کنید (`UniFiMapper-v1.0-signed.apk`).
2. تنظیمات → «نصب برنامه‌های ناشناس» را برای مرورگر/فایل‌منیجر فعال کنید.
3. نصب کنید. حداقل اندروید: **5.0 (API 21)** — امضای v1+v2+v3.

## نکات استفاده

- برای اسکن وای‌فای، مجوز **موقعیت مکانی** لازم است (الزام اندروید) و GPS روشن باشد.
- ابتدا ناحیه بسازید، چند نقطه مرجع ثبت کنید، فاصله معلوم را برای کالیبراسیون وارد کنید.
- مقیاس و موقعیت‌ها تقریبی‌اند؛ پیش از تصمیم اجرایی با ابزار میدانی کنترل کنید.
- مدل UniFi را دقیق ثبت کنید (مثلاً U6 Pro، U7 Pro) تا گزارش خروجی برای پروژه جانمایی قابل استفاده باشد.

## بیلد از سورس

- روی هر push به `main`، گیت‌هاب اکشن APK امضاشده را می‌سازد و در Release با تگ `latest` می‌گذارد.
- بیلد محلی: `./gradlew assembleRelease` (JDK 17)

## امضا (Keystore)

- فایل: `keystore/release.keystore` (PKCS12، alias: `unifimapper`)
- رمزها در `gradle.properties` (`IM_STORE_PASS` / `IM_KEY_PASS`)
- ⚠️ برای به‌روزرسانی‌های بعدی همین keystore را نگه دارید تا امضا تغییر نکند.

## ساختار سورس

```
app/src/main/java/com/unifimapper/org/
├── MainActivity.kt     # پنج صفحه + تنظیمات + همه منطق UI
├── Model.kt            # مدل داده + JSON + پروژه DEMO + QC
├── Store.kt            # ذخیره‌سازی محلی پروژه‌ها
├── WifiEngine.kt       # اسکن واقعی WifiManager
├── TopView.kt          # نمای بالا 2D (شبکه متریک، جانمایی، پوشش)
├── PerspectiveView.kt  # پرسپکتیو ۶۰ درجه
├── CamHud.kt           # اورلی دوربین
└── Exporter.kt         # خروجی PNG / OBJ (3ds Max) / JSON
```
